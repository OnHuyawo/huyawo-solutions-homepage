HUYAWO SOLUTIONS HOMEPAGE

DEPLOYMENT

Upload index.html, style.css, script.js, and the assets folder to the same public directory. Keep the existing file and folder names.

CONTACT FORM

The contact form sends submissions to antonio@huyawo.com through FormSubmit. The first live submission triggers an activation email. Open that email and activate the form once. Later submissions will be delivered to the same inbox.
